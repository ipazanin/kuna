# English and Croatian

A typed dictionary with English as the source and Croatian typed against it, so a missing string fails the type check. Plurals go through `Intl.PluralRules`, dates and numbers follow the language, and the choice is kept per device like the theme. Loans and the shell went first, then Company by screen group with a native-speaker review.
