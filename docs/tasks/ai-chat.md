# AI chat across the apps

With a key set up, AI is a first-class part of Kuna, and without one it stays hidden. The app tells it everything it supports and how to set things up. It reads data only if the owner allows, proposes changes the owner accepts, and never reaches secrets or keys files. The chat sits in the app rather than in a popup, and it carries a label for the app in context.

The plan: [the AI chat plan](../features/ai-assist/chat-plan.md).
